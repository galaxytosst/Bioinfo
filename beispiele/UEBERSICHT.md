# Beispielprojekte

Jedes Projekt ist ein Ordner. In der App (Box 1) bei PROJEKTE den Ordnernamen wählen oder ein Thema eintippen, z. B. `prion`, `virus` oder `arten`. Sequenzen aus `accessions.txt` werden beim ersten Start von NCBI geladen. Bei Projekten mit `varianten.txt` werden bekannte Mutationen in eine echte Referenz eingebaut.
